# Xee Harness Enhanced (XHE) Brand Guidelines

To maintain the healthy development of the XHE ecosystem, avoid user confusion, and facilitate resource discovery:

- In descriptive text, you may use "Xee Harness Enhanced" to describe your project's relationship with XHE, e.g. "built on Xee Harness Enhanced" or "compatible with Xee Harness Enhanced".
- For package and project naming, use the abbreviated **XHE** designation (npm scope `@origin-ai/xhe-*`, CLI `xhe`). `X_HARNESS`, `X-HARNESS` and `X HARNESS` in historical docs mean `Xee_HARNESS` / `Xee-HARNESS` / `Xee HARNESS`.
- Avoid using the full "Xee Harness Enhanced" trademark as a standalone project name. Use `XHE` as the concise identifier.
- Do not use official brand materials in a way that implies official endorsement, cooperation or authorization.

Origin AI maintains the XHE distribution. Upstream is DeepSeek Harness (internal reference DSH); public branding in this fork is XHE / Xee Harness Enhanced.

We may contact parties that do not comply to coordinate adjustments. Thank you for helping keep the ecosystem clear and sustainable.
